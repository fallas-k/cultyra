completa.

Para comprobar que se subió completo: en la consola de Firebase →
Hosting, la nueva versión debe decir "23 archivos" (no 8).


------------------------------------------------------------------
PASO 2 — SUBIR EL SERVIDOR NUEVO A RENDER (esto arregla el correo)
------------------------------------------------------------------
El servidor en https://cultyra-server.onrender.com necesita el código
nuevo (con /api/contacto) y la clave de Resend.

  a) Sube la carpeta cultyra-server actualizada a Render:
     - Si usas GitHub:  git add . / git commit / git push
     - Si es manual:    "Manual Deploy" en el panel de Render

  b) En Render → tu servicio → Environment, agrega:
         RESEND_API_KEY = <<TU_RESEND_API_KEY — GENERA UNA NUEVA, la anterior quedó expuesta>>
     (la clave que generaste en resend.com)

  c) La cuenta de Resend debe estar creada con soportecultyra@gmail.com
     (sin dominio propio, Resend solo entrega a ese correo).


------------------------------------------------------------------
PASO 3 — COMPROBAR
------------------------------------------------------------------
Abre:  https://cultyra-server.onrender.com/api/salud
  - Debe incluir  "correo":"configurado"
  - Si dice "sin configurar" → falta el RESEND_API_KEY (Paso 2b)
  - Si NO aparece "correo"   → Render tiene el código viejo (Paso 2a)

Luego abre cultyraagr.web.app en INCÓGNITO, llena el formulario de
"Solicitar Soporte Técnico" y envía. Revisa soportecultyra@gmail.com
